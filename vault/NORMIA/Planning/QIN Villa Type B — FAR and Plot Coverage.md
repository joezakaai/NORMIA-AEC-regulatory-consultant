# QIN Villa Type B — FAR and Plot Coverage

> [!info] [[NORMIA]] · [[Authority Directory]] · [[Qatar]] · Discipline: [[Planning]]
> Source: `Qetaifan Island North District — Planning & Design Guidelines, Residential & Mixed-Use Plots` — REV 2, May 2023, p.92, 98

## Requirement

**Design Guidelines Rev 2, §2.4.2 Villa Type B (Parkside), p.92 — "EXISTING REGULATIONS SUMMARY":**

> Permitted Land Use — Residential
> **Plot Area — As per individual Building Regulations Sheet**
> **Max. FAR — 60 %**
> **Max. Plot Coverage — 50 %**

**Design Guidelines Rev 2, p.98 (Sheet 7/7):**

> **Ancillary buildings must be included in the overall GFA.**

## Value / Criterion

| Parameter | Value | Unit | Notes |
| --- | --- | --- | --- |
| Permitted land use | Residential | — | |
| Maximum FAR | 60 | % | Typology-wide for Villa Type B |
| Maximum plot coverage | 50 | % | Typology-wide for Villa Type B |
| Plot area | Per individual Plot Building Regulation Sheet | m² | **Not fixed by the Design Guidelines** |
| Maximum GFA | FAR × plot area, as stated on the plot's own sheet | m² | Stated numerically on each Plot Building Regulation Sheet |
| Ancillary buildings | Counted within GFA | — | Explicit |

## Design Consequence

FAR and plot coverage are set at typology level and are the same for every Villa Type B
plot. The **plot area and the resulting GFA cap are not** — they come from each plot's own
Plot Building Regulation Sheet, which states the maximum GFA as an absolute figure rather
than leaving it to be computed.

Two consequences that hold across the typology:

1. **Ancillary buildings consume GFA.** A majlis, driver's room, guard room, outside
   kitchen, servant's quarters, storage or pool room all count. On villa plots of this
   size that is routinely 40–70 m² gone before the main house is drawn. Schedule the
   ancillaries before massing.
2. **GFA binds before coverage does.** At 50% coverage a two-storey villa would reach
   100% of the plot area in GFA — far above 60% FAR. **FAR governs the design; coverage
   rarely does.** Teams that mass to the coverage line and then discover the FAR cap lose
   a design stage.

## Interpretation Notes

Where a Plot Building Regulation Sheet states a maximum GFA numerically, **use the stated
figure** rather than recomputing FAR × plot area. Parcel sheets carry a disclaimer that
areas "are approximate and should be used for reference only", so a recomputation from a
disclaimed plot area is less reliable than the number the issuer chose to state.
