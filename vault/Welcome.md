# AEC — AI Consultant

This vault is the regulatory memory for **[[NORMIA]]**, the AEC Regulatory
Intelligence & Compliance Consultant agent.

## How to use it

Ask NORMIA about a plot, a zoning question, a code clause, a drawing set, a BIM
model or a proposed design change. Verified findings get written back here as
records, one per clause, each traced to a document, edition, clause and page.

> [!warning] Never invent compliance
> An empty knowledge base is correct. A populated one built from recollection is
> actively dangerous — the design team will build to whatever number is in here.

Templates are wired to Obsidian's Templates plugin
(`Insert template` → `NORMIA/_templates`).
